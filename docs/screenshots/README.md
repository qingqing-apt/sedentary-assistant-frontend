# 页面截图（验收交付物）

对应任务交付物第 8 项：「页面截图，至少包含活动列表、设置区域、操作后的状态和周统计」。

| 文件 | 内容 | 对应验收场景 |
|---|---|---|
| `01-today-list.png` | 今日活动列表：按时间排序、状态标签（已完成/已推迟）、Agent 建议标签、待处理计数 | 场景 2/3 |
| `02-weekly-stats.png` | 本周完成情况：计划/完成/推迟/跳过四个数字 + 每日进度条 | 场景 11 |
| `03-settings.png` | 时段与偏好设置：上下班、上午/下午窗口、免打扰（可多条）、每天次数、提醒开关 | 场景 1/10 |
| `04-after-action.png` | 操作后的状态：点击「完成」后该条变为「已完成」，待处理数从 7 减为 6 | 场景 3 |

截图环境：本地开发环境 `npm run dev`（前端 5173）+ 后端 8000，登录用户 `intern`。
右下角的悬浮圆点是 CopilotKit 对话入口，底部左侧的开发调试按钮仅在开发模式出现，不影响功能。
